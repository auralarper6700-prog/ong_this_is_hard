# Password Breach

A cybersecurity-themed password game. Build a password that passes every policy rule, then pass multi-factor authentication with a code from your phone, and don't fall for the phishing text.

Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Try the phone feature

Paste this password to pass all 11 rules and bring up the phone:

```
Phishing22!Integrity2026#29
```

The year rule uses the current year from your computer's clock. If the game asks for a different year than 2026, swap it in and adjust the final digits so all digits still add up to 25.

## Run locally

Open `index.html` in a browser.

## Host on GitHub Pages

1. Push these files to the repo root.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch, branch `main`, folder `/ (root)`.
4. Save and wait a minute for the site URL to appear.
